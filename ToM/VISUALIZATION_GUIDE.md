re# Cognitive Action Visualization Guide

This guide describes all visualizations generated by `visualize_cognitive_actions.py` for analyzing the impact of Theory of Mind (ToM) steering on cognitive action activations.

## 📊 Overview

The script creates **15 comprehensive visualizations** divided into two categories:
- **🎯 Baseline vs Steered Comparison Plots (B1-B5)**: Direct comparisons showing how steering changes cognitive actions
- **📊 General Analysis Plots (01-10)**: Broader analyses of patterns, temporal dynamics, and distributions

---

## 🚀 Usage

### Basic Usage (without baseline/steered comparison)
```bash
python visualize_cognitive_actions.py \
  --input results/single_vector_test_summary.json \
  --output-dir visualizations
```

### Full Usage (with baseline/steered comparison)
```bash
python visualize_cognitive_actions.py \
  --input results/single_vector_test_summary.json \
  --raw-csv results/single_vector_test_raw.csv \
  --output-dir visualizations
```

### Parameters
- `--input` / `-i`: Path to summary JSON file (required)
- `--raw-csv`: Path to raw CSV with baseline/steered data (optional, enables B1-B5 plots)
- `--output-dir` / `-o`: Output directory for visualizations (default: `visualizations`)

## 📈 Key Findings from Visualizations

Based on the generated plots, here are the main findings:

### **Top Increased Cognitive Actions (Steered > Baseline)**
1. **emotion_perception** (+2.35): Most increased emotional action
2. **noticing** (+1.59): Enhanced attention and awareness
3. **hypothesis_generation** (+1.57): Improved creative reasoning
4. **emotion_valuing** (+0.94): Increased emotional consideration
5. **suspending_judgment** (+0.82): Better metacognitive control

### **Top Decreased Cognitive Actions (Baseline > Steered)**
1. **questioning** (-1.01): Reduced analytical questioning (at question stage)
2. **convergent_thinking** (-1.48): Reduced after true answer
3. **understanding** (-1.02): Reduced after true answer

### **Accuracy Impact**
- **Baseline accuracy**: 45%
- **Steered accuracy**: 56%
- **Improvement**: +11% (15 samples improved)

### **Probability Shifts**
- **p(true)**: 0.446 → 0.560 (+11.4%)
- **p(wrong)**: 0.554 → 0.440 (-11.4%)

### **Category Effects**
- **Emotional actions**: Largest increases overall
- **Analytical actions**: Mixed effects (some increase, some decrease)
- **Creative actions**: Moderate increases
- **Metacognitive actions**: Selective increases
